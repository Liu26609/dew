## 📖 介绍

**koishi-plugin-dew-bot** 是一款基于《无限恐怖》为蓝本开发的文字 RPG 游戏插件，为 Koishi 框架提供强大的游戏功能支持。

通过本插件，你可以在聊天平台中体验紧张刺激的无限流游戏，感受主神空间的魅力！

---

## ✨ 特色功能

### 🎯 直观的指令系统
- **无需记忆复杂指令** - 采用直观简洁的指令系统，降低学习成本
- **智能交互** - 友好的交互体验，让游戏更易上手

### 🌍 多平台支持
- **广泛兼容** - 支持 QQ、微信、Telegram 等多个主流平台
- **灵活扩展** - 基于服务器的消息处理架构，可接入任何支持 WebSocket 协议的平台
- **技术栈** - 基于 TSRPC 框架，参考 [TSRPC](https://tsrpc.cn/) 可快速接入新平台

### 🚀 高性能架构
- **服务器分离** - 采用服务器端处理架构，保证游戏逻辑的稳定运行
- **实时通信** - 基于 WebSocket 协议，实现低延迟的实时交互
